# 06_report

The 8-10 page report is written online (Google Docs, Overleaf) by the three of us. Only the
exported PDF is versioned here: `report_v1.pdf`, `report_v2.pdf`, ...

Expected structure:

1. Biological context and question
2. Data: origin, size, features, missing values
3. Methods: what was tried and **why**
4. Results: figures and tables from `05_figures/` and `04_results/`
5. Discussion and limitations
6. Contribution of each member (Git history is the evidence)
7. References
